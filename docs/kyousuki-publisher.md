# Kyousuki stock publication lane (inactive until verified)

Uses the existing Drive kyo-suki/short folder through GDRIVE_PARENT_FOLDER_ID, and does not reuse Hiroyuki OAuth or publish through video-publisher. The separate scheduled workflow can reserve at most one new clip per run at 12:00 or 20:00 JST, with durable deduplication and readback. The existing Drive producer and its filename-based stock policy are unchanged. Successfully reserved media is renamed rather than deleted. Uncertain uploads are left pending for reconciliation; no blind retry.

Required Actions variables (do not set rights or authorization until verified): KYOUSUKI_AUTOPUBLISH_ENABLED, KYOUSUKI_SOURCE_RIGHTS_APPROVED, KYOUSUKI_CHANNEL_AUTHORIZED, KYOUSUKI_DESTINATION_CHANNEL_ID. Dedicated Secrets: YT_CLIENT_ID_KYOUSUKI, YT_CLIENT_SECRET_KYOUSUKI, YT_REFRESH_TOKEN_KYOUSUKI. Existing Drive credentials and KYOUSUKI_APPROVALS_JSON remain required.

The existing producer writes review-only stock with all three public flags false. An independently verified publication receipt must bind the exact final media SHA-256, title and description in kirinukiAudit (publicationSha256, publicationTitle, publicationDescription), all three existing public flags, the editorial digest, source MID, episode and exact source grant. The publisher never changes a review flag or generates an approval. The independent final-publication reviewer is not implemented here: ordinary producer output therefore remains nonpublishable. Source permission, transformative content and intended account authorization must be independently established before enabling. This is a conditional delivery path, NOT restored full automation.

Read-only check: python -m scripts.kyousuki_publish. It verifies destination OAuth and the actual folder, counts approved stock and reports redacted blocker codes. No videos uploaded by CI. Do not run any competing legacy poster against this folder. A verified live upload and independent reviewer integration are outstanding.
